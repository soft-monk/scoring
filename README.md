## 它解决什么问题

方案分数与推荐理由没有可复算的来源，自动优化是硬编码的假动作。

## 做 / 不做

| 做 | 不做 |
|---|---|
| 候选生成（规则驱动，可标不适用） | 不产出自然语言话术（交提供方转述） |
| 指标归一与加权评分（过程可导出） | 不做资源合法性校验（只读取结论） |
| 排序、推荐、次优差值 | 不做落库与广播 |
| 结构化可解释输出与审计三件套 | 不做界面方案卡 |
| 受约束的自动优化（单调性保证） |  |
| 采纳 / 确认的状态语义与幂等 |  |
